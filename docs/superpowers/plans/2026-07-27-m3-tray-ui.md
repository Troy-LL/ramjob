# M3 Tray Panel UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a Tauri v2 tray popover (~420×600) instrument hub: system RAM history + hero gauge, Opera-style per-app limit markers, visual overall ceiling with drag→release→vertical ticks, blue Armed / red Warning — wired to M2 `Runtime` / `config.toml` without changing Arming semantics.

**Architecture:** Pure panel helpers live in `ramjob-core` (`cap_math`, `panel` snapshot + mutators, `sys_history`). New `ramjob-app` Tauri v2 crate owns tray, lazy WebView2 panel, and IPC. Frontend is static HTML/CSS/JS in `crates/ramjob-app/ui/` (no React required for M3). Core never trusts raw caps from the panel: always `snap_cap` + §7.5 floor before persist. Ceiling edits are config + history ticks only; they do not call `policy.arm`.

**Tech Stack:** Rust 2021, existing `ramjob-core`, Tauri v2 + WebView2, `serde`/`toml`, light CSS (no purple theme), Windows tray via Tauri.

pub const FLOOR_FLAT_BYTES: u64 = 300 * 1024 * 1024;

- Produces:
```rust
#[derive(Debug, Clone, serde::Serialize)]
pub struct PanelSnapshot {
    pub system_arm: String,           // "Armed" | "Disarmed"
    pub pause_all: bool,
    pub used_bytes: u64,
    pub total_bytes: u64,
    pub overall_limit_bytes: u64,
    pub status_line: String,
    pub warning: bool,                // any LOW_YIELD/THRASHING
    pub samples: Vec<SysSample>,
    pub ceiling_edits: Vec<CeilingEdit>,
    pub groups: Vec<PanelGroup>,
}
#[derive(Debug, Clone, serde::Serialize)]
pub struct PanelGroup {
    pub key: String,
    pub name: String,                 // basename display
    pub gf_bytes: u64,
    pub cap_bytes: u64,
    pub always_enforce: bool,
    pub fsm_hint: String,             // "Idle"|"Pressure"|"Trim"|"LowYield"|"Thrashing"|...
    pub honest: Option<String>,       // SPEC §7.4 message when applicable
}
pub struct PanelState {
    pub config_path: PathBuf,
    pub config: RamjobConfig,
    pub history: SysHistory,
    // optional last known fsm labels: HashMap<String, String>
}
impl PanelState {
    pub fn set_cap(&mut self, key: &str, raw_cap: u64, shift_fine: bool, median_gf: Option<u64>) -> Result<(), String>;
    pub fn set_overall_limit(&mut self, raw: u64, now_unix_ms: u64, shift_fine: bool) -> Result<(), String>;
    pub fn set_pause_all(&mut self, pause: bool) -> Result<(), String>;
    pub fn build_snapshot(
        &self,
        system: SystemArm,
        used_bytes: u64,
        total_bytes: u64,
        groups: &[PanelGroup],
    ) -> PanelSnapshot;
    pub fn diagnostics_text(&self, ring: &DiagnosticsRing) -> String;
}
```

**Status line rules (encode in `build_snapshot`):**
- If `pause_all`: `"Paused — enforcement off"`
- Else if Armed: `"Armed — enforcing caps under memory pressure"`
- Else: `"Idle — caps set but paused until memory gets tight"` (dormant copy)

**`set_overall_limit`:** clamp with `snap_cap_bytes` (no app floor); write `config.overall_limit_bytes`; `history.commit_ceiling`; `save_config_atomic`. Does **not** touch `PolicyState`.

**`set_cap`:** upsert `GroupConfig` by key; `clamp_cap_with_policy`; save.
